# Nathan_Cual_Milestone_4
## Dataset
The full Yelp polarity files (train.csv, test.csv) are too large for GitHub.
Download them from (https://github.com/DrJZhou/Datasets-for-Sentiment-Analysis) and place them in the project folder.

The fixed 300-review test set and my 30 hard cases are included.

Day 3 and the EDA need train.csv; Days 2 and 4 only need the saved 300-review test set so Days 2 and 4 run without the large files.
